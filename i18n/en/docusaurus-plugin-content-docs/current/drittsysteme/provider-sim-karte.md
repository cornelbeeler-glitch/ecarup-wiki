All compatible charging stations and metering devices require internet access.

Internet access can be provided as follows:

- A wired connection from Swisscom, Sunrise or another local internet provider.

- Internet via a mobile SIM card and an Ethernet/Wi-Fi router.

## Setting up Wi-Fi systems

Many of today's systems are built on Wi-Fi. For these systems to work properly, a few things need to be considered.

- Frequency bands

- Signal range

- Positioning of the access points

- Internet connection via mobile data or cable provider


You can find more information on suitable products and tips on the [smart-me Wiki page.](https://wiki.smart-me.com/planung/internetverbindung)
