### IS-E / MSCONS Auto Export

IS-E and MSCONS allow eCarUp charging data to be synchronised automatically (in load profile quality) into the billing systems of an energy utility (EVU) and optionally managed there via an Energy Data Management (EDM) system. The electricity consumed can then be charged to the end customer directly through the existing processes and directly on the electricity invoice. 

Details on implementing the Auto-Export User can be found on the following [page](/funktionen/auto-export-user).

Details on implementing the Auto-Export Meter Reading can be found on the following [page.](https://wiki.smart-me.com/schnittstellen/auto-export)
