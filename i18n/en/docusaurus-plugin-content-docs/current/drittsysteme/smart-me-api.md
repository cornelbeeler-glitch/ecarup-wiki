The smart-me API lets you query meter readings from stations via HTTP requests or use some control functions.

These commands can be used by third-party systems.

The current scope is still limited and will grow over time.

### Currently possible:

- Meter reading queries from OCPP stations (based on session data)

- Meter reading queries from stations with an integrated smart-me / eCarUp meter (based on 15-minute load profile data or faster)

- Current power / currents or voltages and I/O of smart-me / eCarUp meters or stations with this integrated hardware.

- Controlling Pico charging stations and charging groups.


You can find information about the API on this [smart-me Wiki page.](https://wiki.smart-me.com/schnittstellen/api)
