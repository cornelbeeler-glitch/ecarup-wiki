Info:
If there is a difference between your payout and the station report, you can have the files compared here. It is important that both files cover the same time period. If differences have arisen, the comparison lists and explains everything. If you have any further questions, or if there is an actual difference, please send the documents (files) and a short description to [support@ecarup.com](mailto:support@ecarup.com).
The reference for this comparison is the transaction ID.
