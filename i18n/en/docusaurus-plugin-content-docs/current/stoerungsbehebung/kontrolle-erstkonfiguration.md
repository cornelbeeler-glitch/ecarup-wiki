This page describes what you can check during the initial configuration.

## Check the charging station

- The charging station is connected to power and appears in the eCarUp portal as a charge point. \[Image 1\]

- The charging station is displayed in "Blue".

- When the QR code is scanned, a charging session can be started.

    - If you do not know how to generate a QR code, the following page explains it: [QR code](/stationsbetreiber/qr-code)


![Checking the initial configuration – Figure 1](/img/stoerungsbehebung-kontrolle-erstkonfiguration/01.png)

          \[Image 1\]

## Check the settings

- The name of the charging station should be unique.

- The connector type (Anschlusstyp) should be defined

- The max. energy (Max. Energie) should be defined

- The prices should be entered correctly.

- The location is entered so that the charging station appears on the map. (If this is not desired, it can also be left empty)


![Checking the initial configuration – Figure 2](/img/stoerungsbehebung-kontrolle-erstkonfiguration/02.png)

## Account correctly set up / verified

The account should be correctly verified. If you have difficulties with the verification process, you can view the guide here:

⚠️ Important: The account is restricted after a certain period if verification has not taken place. As a result, both incoming payments and payouts can be blocked until the account has been correctly verified.

The message should appear at login if the account has not yet been verified. Once verification is done, the message does not disappear immediately, but remains until the account has passed Stripe's manual verification process.

[Verify account](/stationsbetreiber/account-verifizieren)

![Checking the initial configuration – Figure 3](/img/stoerungsbehebung-kontrolle-erstkonfiguration/03.png)

The payout account should be defined correctly. The company and the payout account should be located in the same country so that the verification process can run smoothly.

![Checking the initial configuration – Figure 4](/img/stoerungsbehebung-kontrolle-erstkonfiguration/04.png)

A VAT rate should be defined if the stations are public and the company is subject to VAT.

![Checking the initial configuration – Figure 5](/img/stoerungsbehebung-kontrolle-erstkonfiguration/05.png)

Support contact information should be defined so that drivers can contact you if they have a problem or a question regarding the charging station. 

This information is visible to every eCarUp driver in the app.

![Checking the initial configuration – Figure 6](/img/stoerungsbehebung-kontrolle-erstkonfiguration/06.png)

## User management for limited charging stations

At charging stations with limited access, only selected users can carry out a charging session. Check whether these users have all been correctly specified and entered. You can do this either under "User management (Benutzerverwaltung)" or under the item "Groups (Gruppen)"

Check the following points:

- Email address entered correctly

- Prices defined correctly

- All users entered correctly


![Checking the initial configuration – Figure 7](/img/stoerungsbehebung-kontrolle-erstkonfiguration/07.png)

## Setting the location correctly

When setting the location, note the following factors:

- Click "Search address (Adresse suchen)" so that the address is formatted correctly.

- The red pin should "bounce"

- Drag the red pin to the actual location of the charging station so that, if it is located in a backyard, for example, this is also marked correctly.

- If several charging stations are next to each other (see example), they must be pulled slightly apart so that drivers are not confused.


Once all these points have been taken into account and the location has been set, the charging station should appear on the eCarUp map immediately.

⚠️ Important: Limited stations only appear on the map if you are logged in to an account that has also been granted access to the station.
