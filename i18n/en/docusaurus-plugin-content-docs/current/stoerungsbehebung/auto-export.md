This page describes what you can do if the Auto Export is not working.

## No Data

<div className="row">
<div className="col col--6">

If the Auto Export shows "No data", the problem is usually the email address, which contains a typo, a space or something similar. We recommend checking the email address and correcting it if necessary.

## Timed out tryping to connect!

If the Auto Export shows "Timed out trying to connect!", this is usually because a connection attempt was not successful. 

The cause of the problem is usually the firewall, which has not opened the required ports. Check whether the firewall is blocking connection attempts or certain data traffic.

![Auto Export – Figure 2](/img/stoerungsbehebung-auto-export/02.png)
