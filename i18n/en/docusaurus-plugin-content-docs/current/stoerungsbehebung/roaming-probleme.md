This page describes what you can do if the station has problems with roaming.

## Station not visible

If you have activated Hubject (roaming network) on your station and it does not appear on other platforms, this can have the following reasons:

- It can take up to 72 hours for the station to appear on the various platforms.

- Some charging station platforms do not update their data very often

- To check whether the station is being pushed to Hubject, pick 2–3 platforms and search for the station there. If it is not listed there, this could be due to the following reasons:


## Location was not added correctly

To activate "Hubject", the location must be set correctly on the charging station.
The location may already have been added but not formatted correctly, so it cannot be pushed to the charging network properly.

To set the location correctly, click the three small dots on the right of the charging station and then go to "Set location" ("Standort setzen").

Then enter the address and click "Search address" ("Adresse suchen"). This formats the address automatically and correctly.

The pin must be red and bouncing. It should also be placed correctly so that drivers know exactly where the station is located. You can place it correctly by dragging it with the mouse to the right spot (drag & drop)

So if the station is located in a backyard, you should also place the pin there so that drivers are not confused. 

If several charging stations are located next to each other, we recommend placing them slightly apart from each other on the map so that they are easier to tell apart in the app.

Once everything has been set correctly, it is best to wait about 48h so that the data can be pushed to the roaming network again.
If the station still does not appear on other platforms after 24h, feel free to contact support.

## Connector type and max. energy (kW) were not defined correctly

Another reason why the station does not appear on Hubject can be that the connector type and the power in kW were not specified correctly.

To check this, click the three small dots on the right-hand side of the charging station and go to "Edit connector" ("Anschluss bearbeiten")

![Roaming problems – Figure 3](/img/stoerungsbehebung-roaming-probleme/03.png)

A window then opens in which you can see under "Information" ("Informationen") whether and which connector type and max. energy have been entered correctly. 



Once you have done this, you also need to wait about 48 hours so that the information can be pushed to the "roaming network".

![Roaming problems – Figure 4](/img/stoerungsbehebung-roaming-probleme/04.png)
