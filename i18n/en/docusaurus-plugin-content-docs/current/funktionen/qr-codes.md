## Manual QR code creation

eCarUp stations can be labelled with a QR code. It serves several purposes:

- Users with the eCarUp app can scan the QR code with the app and are taken directly to the correct station.

- Users without the eCarUp app can scan the QR code with their phone camera and make a one-time payment via our web-based [Instant Pay](/fahrer/sofort-bezahl-funktion).

You can create your own QR code.

To do so, first go to "Stations -> QR codes" ("Stationen -> QR-Codes") in the portal.

To create the QR code, select a station in your account and click "Generate" ("Generieren").

The newly created QR code should then appear.

Then click "Download" ("Herunterladen") to download the QR code. You can then use it for the station's signage or label. 

Note: If a user is unable to scan the QR code for any reason (e.g. the smartphone camera is broken), they can enter the code at the following link: [www.ecarup.com/code](http://www.ecarup.com/code/) and initiate a one-time payment.

## Mapping an existing QR code to a new station

1.  Scan the existing QR code with an app or your phone's camera

2.  Copy the station code from the URL. Copy the code after "stations=" (marked in bold in the example below)

e.g. [https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?serial=I4zp6A12urpfdJK9dKRbFbMAhn](https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?station=I4zp6A12urpfdJK9dKRbFbMAhn) 

3.  Under "Manual QR code creation" ("Manuelle QR-Code-Erstellung"), select the station and paste the copied station code into "Custom station code" ("Benutzerdefinierter Stationscode").

4.  Select "Generate" ("Generieren"). 

5.  Select "Cancel" ("Abbrechen").

6.  Check that the code is shown under "Current custom station code" ("Aktueller benutzerdefinierter Stationscode").

Note: Have you already used a custom code for the old station?

If so, the custom code must be deleted in our system; after that, it can be used again. 

You will find the code under "Current custom station code" ("Aktueller benutzerdefinierter Stationscode"). There, click the "Delete" ("Löschen") icon to delete the old QR code so you can generate a new one.

## Label generator

<div className="row">
<div className="col col--8">

As a station operator, you can create your own labels for your charging stations. Three templates are available. Each generates an A4 PDF that is printed on label sheets. We recommend weatherproof labels:

- Small 42.3 x 21.2mm, Zweckform L7911-10

- Medium: 99.1 x 42.3mm, Zweckform J4776-10, Herma 9533

- Large: 99.1 x 67.7mm,  Zweckform L4715-20

When printing, please make sure that the PDF is not scaled.

You can access the label generator here:
[https://ecarup-tools.azurewebsites.net/](https://ecarup-tools.azurewebsites.net/)

1.  Use the link above

2.  Click Login at the top right and use your eCarUp login.

3.  Select Station Labels on the left-hand side.

4.  Your charge points are listed.

5.  Select the desired charge point and click "Create" ("Erstellen").

6.  Choose the appropriate template and then click "Select template" ("Template auswählen").

7.  Fill in the contact details truthfully and click "Create" ("Erstellen").

8.  A PDF with your labels is generated.
