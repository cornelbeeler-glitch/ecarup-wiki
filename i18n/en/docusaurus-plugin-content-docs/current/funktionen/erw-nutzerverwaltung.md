To use advanced user management, you need an eCarUp Premium licence.

With advanced user management, prices can be set for entire groups of users and assigned to station groups. This greatly simplifies managing many users in larger charging station parks.

To create a user group and define its prices, proceed as follows:

1.  Log in to your eCarUp account.

2.  Go to the menu item Stations (Stationen) and then to Groups (Gruppen).

3.  Create a user group and give it a name (e.g. Sales group, Customers, Employees etc.).


![Advanced user management – Figure 1](/img/funktionen-erw-nutzerverwaltung/01.png)

Important: For a user to be added, they must already have registered. 

4\. Select the group you want to edit.

5\. You can now add users manually or upload entire user groups via a CSV file.

![Advanced user management – Figure 2](/img/funktionen-erw-nutzerverwaltung/02.png)

6\. Create a station group (if one does not already exist) with the relevant stations. Then click Save (Speichern).  

![Advanced user management – Figure 3](/img/funktionen-erw-nutzerverwaltung/03.png)

7\. Once the station group has been created, a price rule can be created for the group. To do this, click the three dots at the top right  and then Price rules (Preisregeln).

Please note the following: If a user is assigned to a group (e.g. Sales eCarUp) and has also been assigned individually as a user to a connector or charge point, eCarUp does not apply the group price but that of the individual driver. 

![Advanced user management – Figure 4](/img/funktionen-erw-nutzerverwaltung/04.png)

8. You can now select a user group (e.g. Sales eCarUp) and define a price per kWh and a price per h.

![Advanced user management – Figure 5](/img/funktionen-erw-nutzerverwaltung/05.png)

## The price rule is now also displayed for the individual stations under Manage users (Benutzer verwalten).

![Advanced user management – Figure 6](/img/funktionen-erw-nutzerverwaltung/06.png)
