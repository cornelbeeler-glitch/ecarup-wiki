## Création manuelle d'un code QR

Les stations eCarUp peuvent être munies d'un code QR. Celui-ci remplit plusieurs fonctions :

- Les utilisateurs de l'app eCarUp peuvent scanner le code QR avec l'app et arrivent alors directement à la bonne station.

- Les utilisateurs sans l'app eCarUp peuvent scanner le code QR avec l'appareil photo de leur téléphone, puis payer une seule fois via notre [paiement instantané](/fahrer/sofort-bezahl-funktion) basé sur le web.

Il est possible de créer votre propre code QR.

Pour cela, allez d'abord dans le portail sous « Stations -> Codes QR » (« Stationen -> QR-Codes »).

Pour créer le code QR, sélectionnez une station de votre compte et cliquez sur « Générer » (« Generieren »).

Le code QR nouvellement créé devrait ensuite apparaître.

Cliquez ensuite sur « Télécharger » (« Herunterladen ») pour télécharger le code QR. Il peut ensuite être utilisé pour l'inscription ou l'étiquette de la station. 

Remarque : si, pour une raison inconnue, un utilisateur ne peut pas scanner le code QR (p. ex. l'appareil photo du smartphone est défectueux), il peut saisir le code sous le lien suivant : [www.ecarup.com/code](http://www.ecarup.com/code/) et initier un paiement unique.

## Reprendre un code QR existant sur une nouvelle station

1.  Scanner le code QR existant avec une app ou l'appareil photo du téléphone

2.  Copier le code de la station à partir de l'adresse URL. Copier le code qui suit « stations= » (marqué en gras dans l'exemple ci-dessous)

p. ex. [https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?serial=I4zp6A12urpfdJK9dKRbFbMAhn](https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?station=I4zp6A12urpfdJK9dKRbFbMAhn) 

3.  Sous « Création manuelle de code QR » (« Manuelle QR-Code-Erstellung »), sélectionner la station et coller le « Code de station personnalisé » (« Benutzerdefinierter Stationscode ») qui a été copié.

4.  Sélectionner « Générer » (« Generieren »). 

5.  Sélectionner « Annuler » (« Abbrechen »).

6.  Vérifier que le code apparaît sous « Code de station personnalisé actuel » (« Aktueller benutzerdefinierter Stationscode »).

Remarque : avez-vous déjà utilisé un code personnalisé pour l'ancienne station ?

Si c'est le cas, le code personnalisé doit être supprimé dans notre système ; il peut ensuite être réutilisé librement. 

Vous trouvez le code sous « Code de station personnalisé actuel » (« Aktueller benutzerdefinierter Stationscode ») ; vous pouvez y cliquer sur le symbole « Supprimer » (« Löschen ») pour supprimer l'ancien code QR et en générer un nouveau.

## Générateur d'étiquettes

<div className="row">
<div className="col col--8">

En tant qu'exploitant de stations, vous pouvez créer vos propres étiquettes pour vos bornes de recharge. Trois modèles sont disponibles. Un PDF au format A4 est généré à chaque fois, destiné à être imprimé sur des étiquettes. Nous recommandons des étiquettes résistantes aux intempéries :

- Petit : 42.3 x 21.2mm, Zweckform L7911-10

- Moyen : 99.1 x 42.3mm, Zweckform J4776-10, Herma 9533

- Grand : 99.1 x 67.7mm,  Zweckform L4715-20

Lors de l'impression, veuillez noter que le PDF ne doit pas être mis à l'échelle.

Vous accédez au générateur d'étiquettes ici :
[https://ecarup-tools.azurewebsites.net/](https://ecarup-tools.azurewebsites.net/)

1.  Utilisez le lien mentionné ci-dessus

2.  Cliquez en haut à droite sur Login et utilisez pour cela votre login eCarUp.

3.  Sélectionnez Station Labels sur le côté gauche.

4.  Vos points de recharge sont listés.

5.  Sélectionnez le point de recharge souhaité et cliquez sur « Créer » (« Erstellen »).

6.  Choisissez le modèle qui vous convient, puis cliquez sur « Sélectionner le modèle » (« Template auswählen »).

7.  Remplissez les coordonnées de manière véridique et cliquez sur « Créer » (« Erstellen »).

8.  Un PDF contenant vos étiquettes est généré.
