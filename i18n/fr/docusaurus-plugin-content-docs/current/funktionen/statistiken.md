L'utilisation des statistiques nécessite une licence eCarUp Premium 

La fonction « Statistiques » (Statistiken) affiche la consommation, les recettes, le nombre de sessions de recharge ainsi que la durée de recharge correspondante, et ce pour : 

- Toutes les stations

- Des stations individuelles

- Tous les groupes de stations

- Des groupes de stations individuels
