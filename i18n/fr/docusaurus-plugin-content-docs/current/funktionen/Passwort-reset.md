Cette page décrit comment réinitialiser le mot de passe sur eCarUp.

<Embed src="https://demo.arcade.software/O26pAuFgHpDQSRr1ejif?embed&embed_mobile=tab&embed_desktop=inline&show_copy_link=true" aspect="1.730" title="Réinitialiser le mot de passe" />

Si vous avez un compte eCarUp mais ne parvenez plus à vous connecter, la raison la plus probable est que vous avez saisi un mot de passe erroné. Les mots de passe eCarUp n'ont pas de durée de validité : une fois défini, un mot de passe ne peut être modifié que par l'utilisateur du compte. eCarUp n'a ni accès aux mots de passe ni la possibilité de les modifier.

Si vous ne vous souvenez plus de votre mot de passe, cliquez sur « Mot de passe oublié ? » (Passwort vergessen?).

Après avoir saisi votre adresse e-mail, cliquez sur « Envoyer » (Senden).

Si l'adresse e-mail a été saisie correctement, un e-mail de smart-me, notre société mère, devrait apparaître dans votre boîte de réception.

Remarque : cet e-mail provient de smart-me, car le compte eCarUp est lié au compte de notre société mère smart-me.

Si l'e-mail n'arrive pas, vérifiez deux points :

- Que l'adresse e-mail a été saisie correctement ci-dessus, car aucun message d'erreur ne s'affiche en cas de saisie erronée. Ce message d'erreur n'apparaît pas, afin qu'il ne soit pas possible de savoir si un compte existe ou non, ce qui permet d'éviter des attaques potentielles.

- Vérifiez également votre dossier SPAM.

Cliquez sur le lien pour être redirigé vers une nouvelle page. Veillez à ce que l'ensemble du lien soit en bleu. Si ce n'est pas le cas, votre fournisseur de messagerie ne l'a pas interprété correctement. Copiez alors le lien et collez-le dans votre navigateur.

Dès que vous avez cliqué sur le lien ou que vous l'avez collé dans votre navigateur, vous devriez être redirigé vers une nouvelle page de smart-me. Vous devriez pouvoir y définir un nouveau mot de passe.

Si « Ajouter un nouveau mot de passe » (Ein neues Passwort hinzufügen) n'apparaît pas, cela peut avoir deux causes :

- Vous ne devez pas être connecté avec un autre compte smart-me ou eCarUp. Sinon, vous modifiez le mot de passe du compte connecté.

- Si l'écran « Ajouter un nouveau mot de passe » (Ein neues Passwort hinzufügen) n'apparaît pas, il peut arriver, surtout sur les appareils iOS/Apple, que le lien ou l'URL soit tronqué. Vous reconnaissez ce problème au fait que l'URL n'est pas bleue sur toute sa longueur. Dans ce cas, vous ne pouvez pas réinitialiser le mot de passe en cliquant simplement sur le lien. Vous devez copier le lien et le coller dans votre navigateur.

Pour modifier le mot de passe, vous pouvez maintenant saisir ici votre nouveau mot de passe. Veillez à ce qu'il ne contienne pas les caractères £,$, car ceux-ci pourraient provoquer des erreurs.

Cliquez ensuite sur « Enregistrer le nouveau mot de passe » (Neues Passwort speichern) pour définir le nouveau mot de passe.

Vous êtes redirigé vers la page de connexion de smart-me. Ne vous y connectez pas, mais retournez sur la page de connexion d'eCarUp.

Dès que vous êtes de retour sur la page de connexion d'eCarUp, vous pouvez vous connecter avec votre adresse e-mail et votre nouveau mot de passe.
