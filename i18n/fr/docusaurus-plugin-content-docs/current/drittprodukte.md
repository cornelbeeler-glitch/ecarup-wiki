### Remarque concernant l'iPhone d'Apple (iOS) :

Android reconnaît presque tous les types de puces. Apple restreint toutefois fortement l'interface NFC du côté du fabricant : les puces plus anciennes ou propriétaires (p. ex. Mifare Classic ou Legic), souvent utilisées sur les cartes de recharge, sont bloquées par iOS pour des raisons de sécurité. eCarUp n'a aucune influence à ce sujet.

Si votre iPhone ne reconnaît pas la carte :

- Saisie manuelle : saisissez simplement à la main le numéro de carte imprimé (UID, si disponible) dans l'app eCarUp (sans espaces).

- Enregistrement via Android : connectez-vous une seule fois sur un appareil Android avec votre compte eCarUp et scannez-y la carte. Elle est ensuite immédiatement enregistrée dans votre compte.
