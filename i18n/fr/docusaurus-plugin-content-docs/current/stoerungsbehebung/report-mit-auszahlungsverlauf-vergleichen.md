Info :
Si vous constatez une différence entre votre versement et le rapport de la station (Stations Report), vous pouvez faire comparer les fichiers ici. Il est important que les deux fichiers portent sur la même période. Si des différences sont apparues, la comparaison les répertorie et les explique en détail. Si vous avez encore des questions ou s'il existe une différence réelle, je vous prie d'envoyer les documents (fichiers) ainsi qu'une brève description à [support@ecarup.com](mailto:support@ecarup.com).
La référence pour cette comparaison est l'ID de transaction (Transaktions ID).
