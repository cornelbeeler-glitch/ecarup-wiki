Cette page décrit les points que vous pouvez contrôler lors de la configuration initiale.

## Contrôler la borne de recharge

- La borne de recharge est raccordée au courant et apparaît comme point de recharge dans le portail eCarUp. \[Image 1\]

- La borne de recharge s'affiche en « bleu ».

- Lorsque le QR code est scanné, il est possible de démarrer une recharge.

    - Si vous ne savez pas comment générer un QR code, la page suivante l'explique : [QR code](/stationsbetreiber/qr-code)


![Contrôle de la configuration initiale – Illustration 1](/img/stoerungsbehebung-kontrolle-erstkonfiguration/01.png)

          \[Image 1\]

## Contrôler les paramètres

- Le nom de la borne de recharge doit être unique.

- Le type de connecteur (Anschlusstyp) doit être défini

- L'énergie max. (Max. Energie) doit être définie

- Les prix doivent être saisis correctement.

- L'emplacement est renseigné, de sorte que la borne de recharge apparaisse sur la carte. (Si cela n'est pas souhaité, le champ peut aussi rester vide)


![Contrôle de la configuration initiale – Illustration 2](/img/stoerungsbehebung-kontrolle-erstkonfiguration/02.png)

## Compte correctement configuré / vérifié

Le compte doit être correctement vérifié. Si vous rencontrez des difficultés avec le processus de vérification, vous pouvez consulter le guide ici :

⚠️ Important : le compte est restreint après un certain temps si la vérification n'a pas eu lieu. Les paiements entrants comme sortants peuvent ainsi être bloqués jusqu'à ce que le compte ait été correctement vérifié.

Le message devrait apparaître lors de la connexion si le compte n'a pas encore été vérifié. Une fois la vérification effectuée, le message ne disparaît pas immédiatement, mais reste affiché jusqu'à ce que le compte ait passé le processus de vérification manuelle de Stripe.

[Vérifier le compte](/stationsbetreiber/account-verifizieren)

![Contrôle de la configuration initiale – Illustration 3](/img/stoerungsbehebung-kontrolle-erstkonfiguration/03.png)

Le compte de versement doit être correctement défini. L'entreprise et le compte de versement doivent se trouver dans le même pays, afin que le processus de vérification puisse se dérouler sans problème.

![Contrôle de la configuration initiale – Illustration 4](/img/stoerungsbehebung-kontrolle-erstkonfiguration/04.png)

Un taux de TVA doit être défini si les bornes sont publiques et que l'entreprise est assujettie à la TVA.

![Contrôle de la configuration initiale – Illustration 5](/img/stoerungsbehebung-kontrolle-erstkonfiguration/05.png)

Les coordonnées du support doivent être définies, afin que les conducteurs puissent vous contacter s'ils ont un problème ou une question concernant la borne de recharge. 

Ces informations sont visibles dans l'app pour chaque conducteur eCarUp.

![Contrôle de la configuration initiale – Illustration 6](/img/stoerungsbehebung-kontrolle-erstkonfiguration/06.png)

## Gestion des utilisateurs pour les bornes de recharge à accès limité

Pour les bornes de recharge à accès limité, seuls les utilisateurs sélectionnés peuvent effectuer une session de recharge. Contrôlez si tous ces utilisateurs ont été correctement indiqués et enregistrés. Vous pouvez le faire soit sous « Gestion des utilisateurs » (Benutzerverwaltung), soit sous le point « Groupes » (Gruppen)

Contrôlez les points suivants :

- Adresse e-mail correctement indiquée

- Prix correctement définis

- Tous les utilisateurs correctement saisis


![Contrôle de la configuration initiale – Illustration 7](/img/stoerungsbehebung-kontrolle-erstkonfiguration/07.png)

## Définir correctement l'emplacement

Lors de la définition de l'emplacement, tenez compte des facteurs suivants :

- Cliquez sur « Rechercher l'adresse » (Adresse suchen), afin que l'adresse soit correctement formatée.

- L'épingle rouge devrait « sauter »

- Faites glisser l'épingle rouge jusqu'à l'emplacement réel de la borne de recharge, de sorte que si celle-ci se trouve par exemple dans une arrière-cour, cela soit aussi correctement indiqué.

- Si plusieurs bornes de recharge se trouvent côte à côte (voir l'exemple), elles doivent être légèrement écartées les unes des autres, afin d'éviter toute confusion chez les conducteurs.


Si tous ces points ont été pris en compte et que l'emplacement a été défini, la borne de recharge devrait apparaître immédiatement sur l'eCarUp-Map.

⚠️ Important : les bornes limitées n'apparaissent sur la carte que si l'on est connecté à un compte qui a également été autorisé pour la borne.
