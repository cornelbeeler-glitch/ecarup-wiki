Cette page décrit la marche à suivre en cas de différences entre le versement et le rapport.

## Différences dans le versement

⚠️ Important : pour créer un rapport, une licence eCarUp-Premium est nécessaire.

Si vous constatez une différence entre le rapport et le versement, vous devez en déterminer la raison.
Pour cela, créez un rapport « CSV étendu » (CSV-Erweitert). 

Tenez compte des éléments suivants :

- La date de votre dernier versement

- La date de votre versement actuel


![Erreurs de rapport – illustration 1](/img/stoerungsbehebung-report-fehler/01.png)

Pour l'explication des termes figurant dans le rapport, vous pouvez consulter cette page.

L'essentiel en bref est le statut de paiement (Payment Status) : 

- Paid = payé - la recharge a été payée par le conducteur et tout est correct.

- notCharged = montant trop faible - aucune facturation n'a eu lieu.

- Failed = l'argent ne peut pas être prélevé auprès du client.




Les différences surviennent le plus souvent lorsque certains conducteurs / certaines recharges présentent un statut « notCharged » ou « Failed ».

Additionnez les montants et comparez-les avec le décompte ; le montant devrait alors concorder.
