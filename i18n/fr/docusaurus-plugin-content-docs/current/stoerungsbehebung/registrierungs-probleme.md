Si vous rencontrez des problèmes lors de l'inscription, aucun message d'erreur explicite ne s'affiche généralement. Cela peut être dû au fait que l'adresse e-mail a été saisie avec des caractères spéciaux ou que le mot de passe contient l'un de ces caractères spéciaux :

⚠️ Important : le mot de passe peut fonctionner sur d'autres plateformes, par exemple l'application Android ou le portail web, car celles-ci ne présentent pas les mêmes problèmes avec les caractères spéciaux.
