Conditions préalables : seuls les Goldpartner eCarUp peuvent utiliser l'export automatique des données

![Export fournisseurs d'énergie – Illustration 1](/img/drittsysteme-export-energieversorger/01.png)

### Export automatique IS-E / MSCONS

Via IS-E et MSCONS, les données de recharge eCarUp peuvent être synchronisées automatiquement (en qualité courbe de charge) dans les systèmes de décompte d'une entreprise d'approvisionnement en électricité (EAE) et y être gérées, en option, au moyen d'un système de gestion des données énergétiques (EDM). Les prélèvements d'électricité peuvent ensuite être facturés au client final directement via les processus déjà existants et directement sur la facture d'électricité. 

Vous trouverez les détails sur la mise en œuvre de l'Auto-Export User sur la [page](/funktionen/auto-export-user) suivante.

Vous trouverez les détails sur la mise en œuvre de l'Auto-Export relevé du compteur (Auto-Export Zählerstand) sur la [page suivante.](https://wiki.smart-me.com/schnittstellen/auto-export)
