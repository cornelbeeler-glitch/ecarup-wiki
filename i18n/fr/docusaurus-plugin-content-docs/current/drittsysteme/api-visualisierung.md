Arcade Solution AG est une entreprise suisse spécialisée dans les solutions TIC.  L'intégration eCarUp permet de réaliser les points suivants :

- Créer ses propres tableaux de bord

- Intégration optionnelle de capteurs de stationnement, dont les données peuvent être combinées et analysées avec celles d'eCarUp

- Analyses générales des points de recharge ainsi que du chiffre d'affaires

- L'interface flexible permettra à l'avenir de nombreux autres cas d'utilisation


Vous trouverez ici un exemple pratique déjà réalisé par un partenaire de projet commun : 

- [Ville de Lucerne](https://www.ewl-luzern.ch/no_cache/privatkunden/dienstleistungen/mobilitaet/pilotprojekt-gruene-zonen/)


![Visualisation API – Illustration 2](/img/drittsysteme-api-visualisierung/02.png)

Exemple : l'analyse des bornes de recharge de smart-me AG. Les bornes de recharge Pico sont exploitées selon une forme mixte de cas d'utilisation publics et limités.

Les bornes de recharge accessibles au public génèrent des recettes, tandis que les collaborateurs peuvent recharger gratuitement aux bornes limitées.

Exemple : taux d'utilisation de chaque point de recharge en termes de recettes et de durée d'utilisation (indépendamment des recettes)
