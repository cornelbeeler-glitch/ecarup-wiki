## Gérer la licence Premium dans le portail web

Vous pouvez activer la licence Premium dans le portail web eCarUp. Vous trouverez toutes les informations importantes à ce sujet sous le lien suivant : [Licences](/stationsbetreiber/lizenzen)

 Information importante : en tant que partenaire eCarUp, vous pouvez commander des licences de 10 ans directement chez nous. Il vous suffit pour cela de nous écrire à [verkauf@ecarup.com](mailto:verkauf@ecarup.com).
