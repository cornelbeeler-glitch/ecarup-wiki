Info:
Se c'è una differenza tra il tuo pagamento e lo Stations Report, puoi far confrontare i file qui. È importante che entrambi i file coprano lo stesso periodo di tempo. Se sono emerse differenze, il confronto le elenca e le spiega tutte. Se hai ancora domande o se c'è effettivamente una differenza, ti chiedo di inviare la documentazione (i file) e una breve descrizione a [support@ecarup.com](mailto:support@ecarup.com).
Il riferimento per questo confronto è l'ID della transazione.
