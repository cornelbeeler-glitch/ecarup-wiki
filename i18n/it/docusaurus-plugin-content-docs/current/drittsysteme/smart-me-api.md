Tramite la smart-me API puoi richiedere le letture del contatore delle stazioni mediante richieste http o utilizzare in parte funzioni di controllo.

Questi comandi possono essere utilizzati da sistemi di terze parti.

Le funzionalità attuali sono ancora limitate e verranno ampliate nel tempo.

### Attualmente possibile:

- Richieste della lettura del contatore di stazioni OCPP (sulla base dei dati delle sessioni)

- Richiesta della lettura del contatore di stazioni con contatore smart-me / eCarUp integrato (sulla base di dati del profilo di carico a 15 minuti o più rapidi)

- Potenza attuale / correnti o tensioni e I/O di contatori smart-me / eCarUp o di stazioni con questo hardware integrato.

- Controllo di stazioni di ricarica Pico e gruppi di ricarica.


Le informazioni sull'API sono disponibili in questa [pagina del wiki smart-me.](https://wiki.smart-me.com/schnittstellen/api)
