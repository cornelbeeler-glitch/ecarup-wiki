Arcade Solution AG è un'azienda svizzera specializzata in soluzioni ICT.  Con l'integrazione di eCarUp si possono realizzare i seguenti punti:

- Creare dashboard personalizzate

- Integrazione opzionale di sensori di parcheggio, i cui dati possono essere combinati e analizzati con quelli di eCarUp

- Analisi generali dei punti di ricarica e del fatturato

- L'interfaccia flessibile consentirà in futuro molti altri casi d'uso


Qui trovi un esempio pratico già realizzato da un partner di progetto comune: 

- [Città di Lucerna](https://www.ewl-luzern.ch/no_cache/privatkunden/dienstleistungen/mobilitaet/pilotprojekt-gruene-zonen/)


![Visualizzazione API – Figura 2](/img/drittsysteme-api-visualisierung/02.png)

Esempio: l'analisi delle stazioni di ricarica di smart-me AG. Le stazioni di ricarica Pico sono gestite in una forma mista di casi d'uso pubblici e limitati.

Presso le stazioni di ricarica accessibili al pubblico si incassa denaro, mentre presso le stazioni limitate i collaboratori possono ricaricare gratuitamente.

Esempio: utilizzo di ogni singolo punto di ricarica in termini di incassi e durata di utilizzo (indipendentemente dagli incassi)
