Requisiti: solo i partner Gold di eCarUp possono utilizzare l'esportazione automatica dei dati

![Esportazione per aziende elettriche – Figura 1](/img/drittsysteme-export-energieversorger/01.png)

### Esportazione automatica IS-E / MSCONS

Tramite IS-E e MSCONS, i dati di ricarica eCarUp possono essere sincronizzati automaticamente nei sistemi di conteggio di un'azienda di approvvigionamento elettrico (AAE), con qualità della curva di carico. Lì possono essere gestiti facoltativamente tramite un sistema di gestione dei dati energetici (EDM). In seguito, i prelievi di corrente possono essere fatturati al cliente finale tramite i processi già esistenti, direttamente sulla fattura dell'elettricità.

Per i dettagli sull'implementazione dell'Auto-Export User consulti la seguente [pagina](/funktionen/auto-export-user).

Per i dettagli sull'implementazione dell'esportazione automatica della lettura del contatore (Auto-Export Zählerstand) consulti la seguente [pagina.](https://wiki.smart-me.com/schnittstellen/auto-export)
