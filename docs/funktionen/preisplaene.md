Um Preispläne nutzen zu können, benötigst du eine eCarUp-Premium-Lizenz.

## Funktion

- Es wird ein Standard-Preisplan erstellt, damit bei einem ungültigen Preisplan dennoch ein Preis als Referenz genutzt werden kann.

- Preispläne können individuell auf einen Zeithorizont angepasst werden.

- Es kann eine Strafgebühr erhoben werden. Diese wird je nach Konfiguration während des Ladevorgangs fällig und stellt keine Blockiergebühr dar.

- Wenn ein Fahrer/eine Fahrerin versehentlich in zwei unterschiedlichen Preisplänen enthalten ist, wird der günstigere gewählt. 

- Wird ein aktiver Preisplan geändert (z.B. kWh Preis wird angepasst) verschiebt sich die Gültigkeit auf den nächsten Tag. 

- Die Kulanzzeit läuft beim Start des Ladevorganges, unabhängig davon, ob ein Straftarif aktiv ist oder nicht. 

- Gilt nicht für das [Roaming](/funktionen/roaming)


## Wichtig für die Stationsbetreiber

- Dynamische Tarifierung auf kWh Basis geschieht noch nicht. 


- Die neue Preispolitik inklusive Straftarif sollte vor allem den Nutzern mitgeteilt werden, die nur RFID-Karten verwenden. 


## Wichtig für die Fahrer und Fahrerinnen

Die App muss mindestens folgende Version enthalten:

- Android Version: 2.5.8 

- iOS Version: 2.7.1
