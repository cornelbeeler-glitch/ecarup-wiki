Für die Nutzung von erweiterte Nutzerverwaltung benötigst du eine eCarUp Premium Lizenz.

Mit erweiterte Nutzerverwaltung können Preise für ganze Gruppen von Benutzern festgelegt und auf Stationsgruppen zugeordnet werden. So wird die Verwaltung von vielen Nutzern in grösseren Ladestationsparks stark vereinfacht.

Um eine Nutzergruppe zu erstellen und deren Preise zu definieren, gehe bitte wie folgt vor:

1.  Logge dich in deinem eCarUp-Account ein.

2.  Gehe zum Menüpunkt Stationen und danach auf Gruppen.

3.  Erstelle eine Benutzergruppe und gib einen Namen ( z. B. Gruppe Verkauf, Kunden, Mitarbeiter etc.).


![Erweiterte Nutzerverwaltung – Abbildung 1](/img/funktionen-erw-nutzerverwaltung/01.png)

Wichtig: Dass der Nutzer hinzugefügt werden kann, muss er sich bereits registriert haben. 

4\. Wähle die zu bearbeitende Gruppe an.

5\. Nun kannst du manuell User hinzufügen oder per CSV-Datei ganze Nutzergruppen hochladen.

![Erweiterte Nutzerverwaltung – Abbildung 2](/img/funktionen-erw-nutzerverwaltung/02.png)

6\. Erstelle eine Stationsgruppe (falls noch nicht vorhanden) mit den entsprechenden Stationen. Klicke danach auf Speichern.  

![Erweiterte Nutzerverwaltung – Abbildung 3](/img/funktionen-erw-nutzerverwaltung/03.png)

7\. Sobald die Stationsgruppe erstellt wurde, kann eine Preisregel für die Gruppe erstellt werden. Hierzu klicke oben rechts auf die drei Punkte  und dann auf Preisregeln.

Bitte beachte Folgendes: Wenn ein User einer Gruppe zugeordnet ist (z. B. Verkauf eCarUp) und gleichzeitig einzeln als Benutzer einem Anschluss oder Ladepunkt zugewiesen wurde, berücksichtigt eCarUp nicht den Preis der Gruppe, sondern den des einzelnen Fahrers. 

![Erweiterte Nutzerverwaltung – Abbildung 4](/img/funktionen-erw-nutzerverwaltung/04.png)

8. Nun kann eine User-Gruppe angewählt werden (z. B. Verkauf eCarUp) und ein Preis pro kWh und Preis pro h definiert werden.

![Erweiterte Nutzerverwaltung – Abbildung 5](/img/funktionen-erw-nutzerverwaltung/05.png)

## Die Preisregel wird nun auch bei den einzelnen Stationen unter Benutzer verwalten angezeigt.
