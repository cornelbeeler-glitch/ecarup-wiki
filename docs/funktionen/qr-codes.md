## Manuelle QR-Code Erstellung

eCarUp Stationen können mit einem QR-Code beschriftet werden. Dieser erfüllt mehrere Funktionen:

- User mit der eCarUp App können den QR-Code mit der App scannen und landen dann bei der richtigen Station.

- User ohne eCarUp App können den QR-Code mit der Handykamera scannen und dann über unser webbasiertes [Sofort-Bezahlen](/fahrer/sofort-bezahl-funktion) einmalig bezahlen.

Es ist möglich einen eigenen QR-Code zu erstellen.

Gehe dazu zuerst im Portal auf "Stationen -> QR-Codes"

Wähle zur Erstellung des QR-Codes eine Station in deinem Account aus und klicke auf "Generieren".

Danach sollte der neu erstellte QR-Code auftauchen.

Klicke danach auf "Herunterladen", um den QR-Code herunterzuladen. Dieser kann danach für die Anschrift oder das Label der Station verwendet werden. 

Hinweis: Kann ein User aus einem unbekannten Grund den QR-Code nicht scannen (z.B. Kamera des Smartphone ist defekt), kann er unter folgendem Link: [www.ecarup.com/code](http://www.ecarup.com/code/) den Code eingeben und eine Einmalzahlung initiieren.

## Bestehender QR-Code auf einer neuen Station abbilden

1.  Vorhandene QR-Code mit einer App oder der Kamer des Telefons scannen

2.  Stationscode aus der URL-Adresse heraus kopieren. Der Code nach dem "stations=" herauskopieren (im untren Beispiel fett Markiert)

z.B. [https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?serial=I4zp6A12urpfdJK9dKRbFbMAhn](https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?station=I4zp6A12urpfdJK9dKRbFbMAhn) 

3.  Unter "Manuelle QR-Code-Erstellung" die Station wählen und den "Benuterdefinierten Stationscode welcher herauskopiert wurde einfügen.

4.  Generieren wählen. 

5.  Abbrechen wählen.

6.  Prüfen der Code unter "Aktueller benutzerdefinierter Stationscode" ersichtlich ist.

Hinweis: Hast du schon einen Benutzerdefinierten Code für die alte Station verwendet?

Falls dies der Fall ist, muss der Benutzerdefinierte Code in unserem System gelöscht werden, danach kann er wieder frei verwendet werden. 

Den Code findest du unter "Aktueller benutzerdefinierter Stationscode" dort kannst du auf das "Löschen" Symbol klicken, um den alten QR-Code zu löschen, um einen neuen zu generieren.

## Label Generator

<div className="row">
<div className="col col--8">

Als Stationsbetreiber kannst du eigene Labels für deine Ladestationen kreieren. Es stehen drei Templates zur Auswahl. Es wird jeweils ein A4 PDF generiert welches auf Etiketten gedruckt wird. Wir empfehlen wetterfeste Etiketten:

- Klein 42.3 x 21.2mm, Zweckform L7911-10

- Mittel: 99.1 x 42.3mm, Zweckform J4776-10, Herma 9533

- Gross: 99.1 x 67.7mm,  Zweckform L4715-20

Beim Drucken bitte beachten, dass das PDF nicht skaliert werden darf.

Hier gelangst du zum Label Generator:
[https://ecarup-tools.azurewebsites.net/](https://ecarup-tools.azurewebsites.net/)

1.  Verwende den obenerwähnten Link

2.  Klicke oben rechts auf Login, verwende hierfür dein eCarUp Login.

3.  Wähle auf der linken Seite Station Labels aus.

4.  Deine Ladepunkte werden aufgelistet.

5.  Wähle den gewünschten Ladepunkt aus und klicke auf "Erstellen."

6.  Wähle dein passendes Template und klicke im Anschluss auf "Template auswählen."

7.  Fülle die Kontaktdaten wahrheitsgetreu aus und klicke auf "Erstellen."

8.  Ein PDF mit deinen Labels wird generiert.
