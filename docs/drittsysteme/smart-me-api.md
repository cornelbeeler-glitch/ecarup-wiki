Über die smart-me API kannst du mittels http-Abfragen Zählerstände von Stationen erfragen oder teilweise Steuerfähigkeiten nutzen.

Diese Befehle können von Drittsystemen verwendet werden.

Der Aktuelle Umfang ist noch begrenzt und wird mit der Zeit weiter zunehmen.

### Aktuell möglich:

- Zählerstandsabfragen von OCPP Stationen (basierend auf Session-Daten)

- Zählerstandsabfrage von Stationen mit integriertem smart-me / eCarUp Zähler (basierend auf 15-Minuten Lastgang Daten oder schneller)

- Aktuelle Leistung / Ströme oder Spannungen und I/O von smart-me / eCarUp Zählern oder Stationen mit dieser integrierten Hardware.

- Steuern von Pico Ladestationen und Ladegruppen.


Die Informationen zur API findest du auf dieser [smart-me Wiki Seite.](https://wiki.smart-me.com/schnittstellen/api)
