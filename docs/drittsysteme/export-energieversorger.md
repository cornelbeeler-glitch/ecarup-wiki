Voraussetzungen: Nur eCarUp Goldpartner können den automatischen Datenexport nutzen

![Export Energieversorger – Abbildung 1](/img/drittsysteme-export-energieversorger/01.png)

### IS-E / MSCONS Autoexport

Über IS-E und MSCONS können eCarUp Ladedaten automatisiert in die Abrechnungssysteme eines EVU synchronisiert (in Lastgangqualität) und dort optional über ein Energie Daten Management (EDM) verwaltet werden. Danach können die Strombezüge direkt über die bereits bestehenden Prozesse und direkt auf der Stromrechnung dem Endkunden verrechnet werden. 

Details zur Umsetzung vom Auto-Export User finden Sie auf folgender [Seite](/funktionen/auto-export-user).

Details zur Umsetzung vom Auto-Export Zählerstand finden Sie auf folgender [Seite.](https://wiki.smart-me.com/schnittstellen/auto-export)
