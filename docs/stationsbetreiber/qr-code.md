eCarUp Stationen können mit einem QR-Code beschriftet werden. Dieser erfüllt mehrere Funktionen:

- User mit der eCarUp App können den QR-Code mit der App scannen und landen dann bei der richtigen Station.

- User ohne eCarUp App können den QR-Code mit der Handykamera scannen und dann über unser webbasiertes [Sofort-Bezahlen](/fahrer/sofort-bezahl-funktion) einmalig bezahlen.

## Label Generator & Video -Anleitung

Du als Stationsbetreiber kannst ab sofort eigene Labels für deine Ladestationen kreieren. Es stehen drei Templates zur Auswahl. Es wird jeweils ein A4 PDF generiert welches auf Etiketten gedruckt wird. Wir empfehlen wetterfeste Etiketten: 

- Klein 42.3 x 21.2mm, Zweckform L7911-10

- Mittel: 99.1 x 42.3mm, Zweckform J4776-10, Herma 9533

- Gross: 99.1 x 67.7mm,  Zweckform L4715-20

Beim Drucken bitte beachten, dass das PDF nicht skaliert werden darf. 

Hier gelangst du zum Label Generator:
[https://ecarup-tools.azurewebsites.net/](https://ecarup-tools.azurewebsites.net/) 

1.  Verwende den obenerwähnten Link

2.  Klicke oben rechts auf Login, verwende hierfür dein eCarUp Login. 

3.  Wähle auf der linken Seite Station Labels aus.

4.  Deine Ladepunkte werden aufgelistet.

5.  Wähle den gewünschten Ladepunkt aus und klicke auf Create.

6.  Grösse anwählen und auf Continue.

7.  Kontaktdaten ausfüllen und auf weiter klicken. 

8.  Das Label für deine Ladestation wird erstellt.

## QR-Code manuell erstellen & Video-Anleitung

Es ist möglich, einen QR-Code manuell zu erstellen.

Wähle dazu im Webportal die gewünschte Station und klicke auf Generieren. Beachte bitte, dass du bei Stationen mit mehr als einem Anschluss (Connector) diese explizit auswählen musst. 

Wir empfehlen dir für ein optimales Ergebnis stets die Verwendung unseres Label-Generators.

## Bestehender QR-Code auf neue Station abbilden

1.  Vorhandene QR-Code scannen

2.  Stationscode aus der URL-Adresse heraus kopieren. Der Code nach dem "stations=" herauskopieren (im untren Beispiel fett Markiert)

z.B. [https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?serial=I4zp6A12urpfdJK9dKRbFbMAhn](https://www.ecarup.com/InstantPay/InstantPayWithCreditCard.aspx?station=I4zp6A12urpfdJK9dKRbFbMAhn) 

3.  Zum Menu Stationen --> QR-Codes navigieren

4.  Unter "Manuelle QR-Code-Erstellung" die Station wählen und den "Benuterdefinierten Stationscode welcher herauskopiert wurde einfügen.

5.  Generieren wählen. 

6.  Abbrechen wählen.

7.  Prüfen der Code unter "Aktueller benutzerdefinierter Stationscode" ersichtlich ist.

![QR-Code erstellen – Abbildung 12](/img/stationsbetreiber-qr-code/12.png)

### Benutzerdefinierter Stationscode

Hast du schon einen Benutzerdefinierten Code für die alte Station verwendet?

- Der Benutzerdefinierte Code muss in unserem System gelöscht werden, danach kann er wieder frei verwendet werden.
