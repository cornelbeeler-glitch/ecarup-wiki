Zahlungsabgleich

Abgleich über Transaction ID (Stationsreport vs. Saldoverlauf)

Stationsreport Anforderungen

  • Transaction ID: Primärer Abgleichschlüssel
  • Total (Währung): Betrag der Transaktion
  • Start date: Zeitpunkt der Ladung
  • Payment Status: Status (Paid, Success, Failed, etc.)

Saldoverlauf Anforderungen

  • transactionId: Primärer Abgleichschlüssel
  • Amount: Verbuchter Betrag
  • Created: Datum der Verbuchung
  • Reporting Category: Muss "charge" sein
  • Currency: Zur Währungserkennung
Dateien auswählen zum Starten

Analyseergebnis

💡 Analyse-Hinweise

  • • Abgleich erfolgt primär über die Transaction ID.
  • • Status "notcharged": Transaktionen unter 0.50 Einheiten werden oft nicht verbucht.
  • • "Failed" Status im Report bedeutet oft, dass die Zahlung erst später erfolgreich war.
  • • Zeitliche Diskrepanzen entstehen meist durch Banklaufzeiten am Wochenende.
